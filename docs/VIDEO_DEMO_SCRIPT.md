## 🛠️ Recording Settings & Pro-Tips

### Recommended Tools
1. **Loom (Easiest & Best Quality):**
   - Resolution: Set to **1080p HD** or **4K**.
   - Mode: Screen + Cam (Circle webcam in corner).
2. **OBS Studio or QuickTime:**
   - On macOS: Open QuickTime Player $\rightarrow$ `File` $\rightarrow$ `New Screen Recording`.
   - Audio: Select your external microphone (AirPods or USB mic), not default laptop room echo.

### Screen Prep Checklist Before Hitting Record
- [ ] Server running at `http://localhost:8000/`.
- [ ] Browser window zoomed to **100% or 110%** for maximum crispness.
- [ ] Hide browser bookmarks bar (`Cmd + Shift + B` in Chrome) for clean presentation.
- [ ] Close unnecessary background apps and notifications (Turn on macOS **Do Not Disturb**).
- [ ] Test the **▶ START LIVE DEMO** button once beforehand to ensure smooth streaming.
